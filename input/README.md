This directory contains any additional inputs not available via the GEO accession. I provide the YChromosome_genes.txt used for filtering genes in the Experiment 1 DESeq2 script, the reference gff used for rMATS results tables, and the rMATS results used for filtering and plotting as a convenience. Count data inputs are available at GEO under accession GSEGSE330030.

For the deconvolution workflow the seurat reference object is available at [https://portal.brain-map.org/atlases-and-data/rnaseq/mouse-whole-cortex-and-hippocampus-smart-seq.](https://brain-map.org/our-research/cell-types-taxonomies/cell-types-database-rna-seq-data/mouse-whole-cortex-and-hippocampus-smart-seq)
